# EPFL Data Science Projects

This repository contains selected projects from the **Applied Data Science: Machine Learning** program at the **EPFL Extension School** (April–August 2025).

These projects focus on applying machine learning and statistical modeling to real-world challenges in:
- Humanitarian systems
- Risk analysis
- Public health data
- Social impact forecasting

## Project Structure

/notebooks ← Jupyter notebooks (module work, EDA, modeling) 
├── module_01_intro.ipynb /scripts ← Finalized Python scripts (converted from notebooks) /data 
├── raw ← Original datasets (not tracked in Git) 
├── processed ← Cleaned, structured data /outputs ← Visualizations, model artifacts, predictions /reports ← Markdown, PDF, or PowerPoint deliverables

## Tech Stack

- Python 3.11
- NumPy, Pandas, Scikit-learn
- Seaborn, Matplotlib
- JupyterLab / VS Code
- Git & GitHub
